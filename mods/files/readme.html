Troubleshooting

  • (ug1/2/ps) new song strings dont show/music player doesnt show the new songs

    • make sure to have ultimate asi loader installed or any other mod script that depends on it like widescreen fix.

  • (mw/carbon/uc) errors in vlted/ogvi while installing

    • if the game is placed in a restricted directory (like program files) run the tool as admin and then import the script.

  • songs refuse to play when imported

    • files arent replaced properly so replace and double check.


PSP PORTS

first off download DeltaPatcher then grab one of the patches

  • ugr
  • other psp ports
now assuming that you downloaded one of the options and have the american version of underground rivals and if thats not the case get the american version
then convert your save from hardware or alternatively on PPSSPP disable save data encryption and rename the save folder to match the region and after that just open deltapatcher, fill in the blanks and click the cog and tick the option to backup the original file and then apply the patch.

Troubleshooting

  • my game crashes on boot what should i do?

    • if its crashing on boot it usually means that the patch didnt apply correctly just check the integrity of the iso to see if its the right region or not and avoid patching modded iso files.

  • the game skips music on real hardware/performance issues (ugr only)

    • the game has trouble handling sample quality higher than 256k (PPSSPP not affected but the performance does dip for about 5%) so use the psp compatible options.
